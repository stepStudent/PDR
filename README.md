# 🚗 Вебзастосунок «Екзамен ПДР України»

Сучасний повнофункціональний вебзастосунок для проходження фінального теоретичного іспиту з Правил дорожнього руху України за офіційним стандартом сервісних центрів МВС.

---

## 🌟 Основні можливості

### 1. 👥 Два режими авторизації
- **Адміністратор (Екзаменатор / Викладач):**
  - Логін: `admin`
  - Пароль за замовчуванням: `admin`
  - Кнопка **«Змінити пароль»** в адмінській панелі з валідацією поточного пароля.
  - Повний моніторинг результатів усіх користувачів і груп.
  - Створення груп, генерація індивідуальних паролів кандидатам, пакетне додавання учнів.
  - Генерація карток доступу для друку (`🖨️ Друк карток доступу`).

- **Кандидати у водії (Студенти):**
  - Вхід за **навчальною групою**, **прізвищем** та **паролем**, створеним адміністратором.
  - Доступ **тільки до власних результатів** (сувора серверна перевірка прав доступу).
  - Персональний кабінет із переглядом історії спроб та детального розбору помилок.

### 2. 🚦 Офіційний регламент та інтеграція офіційної бази ПДР
- Інтегровано **2 332 офіційні екзаменаційні питання** Головного сервісного центру МВС за 71 тематичним розділом.
- **1 168 дорожніх ситуацій та ілюстрацій** (знаки, регулювання перехресть, розмітка, сигнали регулювальника).
- Структура іспиту відповідає реальному державному тесту:
  - **20 питань** (рандомізована збалансована вибірка дорожніх ситуацій та правил).
  - Таймер зворотного відліку на **20 хвилин** (з кольоровими попередженнями при залишку < 3 хв та < 1 хв).
  - Критерій успішності: **не більше 2 помилок** (18–20 правильних — **СКЛАДЕНО**, 3 і більше помилок або вичерпання часу — **НЕ СКЛАДЕНО**).
  - Навігаційна сітка по 20 питаннях із фіксацією відповідей та можливістю повернення.

### 3. 🔒 Захист результатів від редагування (Immutability & Data Integrity)
- **Тригери бази даних SQLite (WAL mode):**
  - Таблиці `exam_results` та `exam_answers` мають тригери `BEFORE UPDATE` та `BEFORE DELETE`, які автоматично викидають виключення (`ABORT`) на рівні рушія SQLite при будь-якій спробі модифікації або видалення збереженого протоколу.
- **Серверний захист сесій:**
  - Одноразовий життєвий цикл сесії (`is_completed = 1`). Повторне надсилання блокується зі статусом `400 / 403`.
- **Криптографічний цифровий підпис (SHA-256):**
  - Для кожного складеного іспиту генерується унікальний геш-зліпок від даних кандидата, часу та відповідей, що гарантує цілісність протоколу.

### 4. 🌓 Перемикання світлої та темної теми
- В усіх інтерфейсах (авторизація, кабінет учня, симулятор іспиту, панель адміністратора) у верхній навігаційній панелі розміщено інтерактивну **іконку перемикання теми** (сонце ☀️ / місяць 🌙).
- Обрана тема зберігається у `localStorage` та миттєво застосовується без мерехтіння сторінки при повторних заходах.
- Обидві теми повністю адаптовані для комфортного читання питань, дорожніх схем та таблиць результатів.

## 🚀 Швидкий запуск

### Вимоги
- **Node.js** (версія 18 або новіша)
- **npm**

### Команди для запуску
```bash
# Встановлення залежностей (якщо ще не встановлено)
npm install

# Запуск сервера
npm start
```

Після запуску відкрийте браузер за адресою:
👉 **[http://localhost:3000](http://localhost:3000)**
